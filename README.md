One Word, One Username, One Reward — the entry writes the entrant's own
make.fun username, one word and nothing else, to `/output/entry.txt`.
The judge reads two usernames at a time and picks the funnier or more
interesting one.

## Run it

```sh
python3 main.py
```

The program writes exactly `kace2122` (8 characters, a single word, no
trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
deterministically.
